TAPE

A stock and ETF dashboard for learning how to evaluate US stocks, with a live chart
that Claude or ChatGPT can draw on while it explains things.

New here? Open START-HERE.html. It has the full guide.

The short version:

  1. Unzip this folder.
  2. Windows: double-click "Start Tape".
     Mac: right-click "Start Tape.command" and choose Open.
     Linux: run ./start-tape.sh in a terminal.
  3. The first run takes a couple of minutes to set itself up.
  4. To use the AI, add your own Claude or ChatGPT API key in the app.
     A Claude Pro or ChatGPT Plus subscription doesn't include API use.
